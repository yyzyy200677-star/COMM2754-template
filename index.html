Week 5 — Web Scraping with Python

This week, I explored web scraping using Python and BeautifulSoup in Google Colab.

I collected 10 quotes and their authors from the Quotes to Scrape website and exported the results into a CSV file.

This exercise helped me understand how Python can collect information from websites and organise it for digital media research.

Skills: Python, BeautifulSoup, HTML Selectors, Web Scraping and CSV Export.
